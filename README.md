Ce code est un projet Godot simple, qui sert de base à un petit jeu.



Dans le dossier menu\_principal, vous retrouverez la page par défaut du projet. Dans le dossier parametres, vous retrouverez tous ce qui est nécessaire au menu des paramètres. Dans scènes se trouve une scène de base dans laquelle vous pouvez créer votre jeu.

Toutes les ressources nécessaires au projet sont dans le dossier ressources, séparés en fichier en fonction du type de ressources. Quelques ressources de base sont disponibles.



Ce projet comporte un menu principal, avec une image de fond à ajouter, un bouton qui redirige sur la scène principale de base et un bouton qui mène vers les paramètres.

Les paramètres sont perconalisables et ont des blocs qui permettent de gérer le volume d'un bus audio ou de changer des touches. Ils sont personalisables via des paramètres personalisés (pensez bien à changer les match dans les scripts correspodnants). Du code non utilisé sert pour le changement de résolution.



Le code est commenté en grande partie, n'hésitez pas à lire les commentaires.



Bonne jam !
